HTML – Hypertext Markup Language

1. What is HTML and Why do we use HTML?
- HTML is the standard language used to create and design the structure of web pages.
- It structures content on the web (text, images, buttons, forms).
- It makes web pages readable and organized.
- It is the foundation of every website (before adding styles with CSS or functionality with JavaScript).
Program: https://codepen.io/Kiranmai-Ubbani/pen/bNNoEby

2. <!DOCTYPE html>
- DOCTYPE stands for Document Type.
- Used for browser understanding purposes.

3. What are Tags and Elements?
- A tag defines an element on a web page.
- Tags usually come in pairs: opening <tag> and closing </tag>.
- Common Tags:
  h1 to h6 – Headings
  p – Paragraph
  a – Anchor (link)
  img – Image
  div – Division
  span – Inline container
  br – Line break

4. Semantic Elements:
- Define the meaning of the content.
- Examples: header, nav, section, aside, article, main, footer, figure, summary, time

5. Non-Semantic Elements:
- Do not describe their content.
- Examples: div, span, b, i, hr, kbd, p, q, td

6. Difference between div and span:
- div is a block-level element (starts on a new line).
- span is an inline element (does not start on a new line).

7. Iframe and X-Frame:
- iframe embeds another HTML page inside the current one.
- x-frame options prevent a page from being embedded in an iframe.
Syntax: <iframe src="url" title=""></iframe>

8. Attributes:
- Provide additional information about elements.
- Syntax: name="value"
Examples:
  href: hyperlink (<a href="URL">Link</a>)
  src: image source (<img src="image.jpg">)
  alt: alternate text (<img alt="desc">)
  style: inline styles (<p style="color:red">Text</p>)
  lang: page language (<html lang="en">)

9. Formatting Elements:
<b> – Bold
<strong> – Important
<i> – Italic
<em> – Emphasis
<mark> – Highlight
<small> – Small text
<del> – Deleted text
<ins> – Inserted text
<sub> – Subscript
<sup> – Superscript

11. Links:
- Allow navigation between documents/pages.
Syntax: <a href="URL">Link text</a>

12. Link Attributes:
- target="_blank" – Opens in new tab
- target="_self" – Default, same tab
- target="_parent", "_top"

13. Absolute vs Relative URLs:
- Absolute: Full URL (e.g., https://example.com)
- Relative: Path within the site

18. Responsive Web Design:
- Makes websites look good on all devices (desktop, tablet, phone)

19. Meta Tags:
- Provide metadata to the browser (SEO, character set, viewport)
Example: <meta name="viewport" content="width=device-width, initial-scale=1">
